FLUJO DIARIO OBLIGATORIO (REQ-008)
----------------------------------
Orden real de dependencias 4 -> 5 -> 3 -> 6:

    python -m src.analysis.actualizar_mes_actual yadira && python -m src.analysis.informe_fichas_abiertas && python -m src.tools.crear_notas_clinicas --todos && python -m src.analysis.enriquecer_informe

Runner conveniente (mismos 4 pasos, se detiene en el primer fallo):
    python flujo_diario.py

Paso a paso:
    # (4) Actualizar el mes desde Rayen (~2-3 min, requiere login)
    python -m src.analysis.actualizar_mes_actual yadira

    # (5) Informe base (offline, lee data/analysis/fichas_completo.db)
    python -m src.analysis.informe_fichas_abiertas
    #   Variante anual (aislada del mensual, REQ-011):
    python -m src.analysis.informe_fichas_abiertas --todos

    # (6) Enriquecer informe (offline, lee notas_clinicas/)
    python -m src.analysis.enriquecer_informe

    # (3) Scrapear fichas del informe (requiere login)
    python -m src.tools.crear_notas_clinicas --todos --user yadira
    #   Un solo paciente:
    python -m src.tools.crear_notas_clinicas --paciente "Nombre Completo" --fecha dd-mm-yyyy

FLUJO OPT-IN: EXAMENES (REQ-009/012/047)
----------------------------------------
    # (2a) Archivar foto recibida por Telegram (lo normal es via Rubicita)
    python -m src.tools.recibir_foto_examen \
        --input "C:/ruta/a/foto.jpg" \
        --paciente "Nombre Apellido" \
        --fecha dd-mm-yyyy \
        --indice 1

    # (2b) Consolidar via vision z.ai -> data/examenes/exam_<pac>_<fecha>.md
    #      Requiere ZAI_API_KEY en .env (ver .env.example)
    python -m src.tools.consolidar_examenes --paciente "Nombre Apellido"
