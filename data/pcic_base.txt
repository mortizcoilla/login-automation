# ----------------------------------------------------------------------------
# Reglas de customizacion del OBJETIVO
# ----------------------------------------------------------------------------
# Estas reglas las definio Yadira (audios 2026-08-25). Combinarlas con
# "/" cuando apliquen. Si una NO aplica para el paciente, NO incluirla.
#
# Peso / IMC:
# - IMC < 18.5          -> "Ganancia de peso corporal"
# - IMC 18.5-24.9       -> (no agregar objetivo de peso)
# - IMC 25-29.9         -> "Disminuir a lo menos el 5% del peso corporal"
# - IMC >= 30           -> "Disminuir a lo menos el 5% del peso corporal"
# - Perimetro abdominal
#   elevado (>88 cm M,
#   >102 cm H)         -> agregar "disminuir perimetro abdominal"
#
# Presion arterial:
# - HTA dx / PA >= 140/90
#   en este control    -> agregar "control de cifras de presion arterial"
#
# Glicemia / DM2:
# - DM2 dx / glicemia
#   >= 100 ayunas o
#   >= 140 casual      -> agregar "control de glicemia / HbA1c"
#
# Tiroides:
# - Hipotiroidismo dx /
#   TSH elevada        -> agregar "control de cifras de TSH"
#
# Perfil lipidico:
# - Dislipidemia dx /
#   colesterol total
#   >= 200 o LDL
#   >= 100             -> agregar "control de cifras de colesterol"
# - Trigliceridos
#   >= 150             -> agregar "control de cifras de trigliceridos"
#
# Renal:
# - ERC dx / VFG
#   < 60               -> agregar "control de funcion renal"
#
# Multiple condiciones:
# - Combinar con "/" los objetivos que apliquen.
# - Ejemplo HTA + DM2 + sobrepeso:
#   "Disminuir a lo menos el 5% del peso corporal / control de cifras
#    de presion arterial / control de glicemia / HbA1c"
#
# Pacientes sin condiciones claras:
# - Si el paciente NO tiene ninguna de las anteriores, usar el OBJETIVO
#   generico:
#   "Disminuir a lo menos el 5% del peso corporal / control de cifras
#    de tsh y trigliceridos"
#   (es la version original que Yadira entrego como referencia)
# ----------------------------------------------------------------------------
